# Coaching Class Attendance and Fee Management System

## Purpose
A comprehensive system to help coaching institutes manage students, batches, attendance, fee payments, and parent communication in a single platform.

## Key Principles
- **Business-focused**: Solves real-world management problems.
- **Role-based Access Control (RBAC)**: Secure access for different user types.
- **Clean Backend & Secure Data**: Robust architecture prioritizing data integrity.
- **Minimal but Meaningful AI**: AI features that add value without overcomplicating.
- **Explainable Logic**: Transparent processes (no black-box ML).

## Roles
- **Admin**: Full system access.
- **Teacher**: Manage batches, attendance, and student progress.
- **Parent**: View attendance, pay fees, and receive communications.
